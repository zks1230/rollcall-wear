# 使用说明（给班主任）

## 装到手表

1. 手表：设置 → 关于手表 → 连点「版本号」7 次 → 开发者选项 → 打开「USB 调试」；
2. 数据线连电脑，手表弹「允许 USB 调试吗」→ 勾「一直允许」→ 确定；
3. 电脑上：

```powershell
cd C:\Users\Administrator\Downloads\person
.\gradlew.bat :app:assembleDebug
adb devices                                   # 看到设备才算连上
adb install -r app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n com.juhao.rollcall/.MainActivity
```

> 第一次打开会自动导入内置 40 人名单（app/src/main/assets/roster.csv 里的占位名字）。
> 要和 ClassTool 共存没问题，包名不同：`com.juhao.rollcall`。

## 三个页面（左右滑）

### 第 1 页：跑操点名

- 打开就是一片绿 —— **快速模式**默认「全员到齐」，你只需要点没来的人。
- 点一下格子：`到 → 请假 → 迟到 → 缺勤 → 回到到`（按这个顺序循环）。
- 顶部「快速 / 逐个」可切换：
  - **快速**：默认全员到齐，只点异常（跑操 5 秒完成）；
  - **逐个**：默认「未点」，一个一个人点「到」（正式考勤用）。
- 「全到 / 重置」按钮清空当天的标记（快速模式=全员到齐，逐个模式=全部未点）。
- 底部图例：绿=到、黄=请假、蓝=迟到、红=缺勤、灰=未点。

### 第 2 页：收作业

- 默认每人「未交」（红），点一下变「交」（绿）。
- 大多数人都交齐后，先点「全交」一键置绿，再把没交的几个人点回红 —— 比一个个点快。
- 「全未交」要再点一次确认，防止误清。

### 第 3 页：统计

- 近 7 天：缺勤次数排行、作业未交排行（谁最常出问题一眼看到）；
- 「导出 CSV」把全部记录写成文件；
- 下面是「历史记录」「名单管理」「设置」入口。

## 换成本班的名单

**方法 A（推荐，一次到位）**：改 `app/src/main/assets/roster.csv`，一行一个名字，重新编译安装。
只有第一次启动会导入，已经装过的话先在「设置 → 恢复内置名单」里恢复一次，或者卸载重装。

**方法 B（手表上改）**：统计页 → 名单管理
- 「批量导入」：把名单（微信复制的也可以）粘进输入框，自动识别，选「追加」或「替换」；
- 点某个学生：改名、上移/下移调学号顺序、删除；
- 「+ 添加学生」：临时加人。

> 替换名单时按名字沿用旧 id，已经记过的出勤/作业不会错位。

## 导出到电脑

1. 手表：统计页 → 「导出 CSV」；
2. 数据线连电脑后：

```powershell
adb pull /sdcard/Android/data/com.juhao.rollcall/files/ .\export\
```

得到 `点名记录_20261031_1745.csv`，内容四列：`日期,姓名,出勤,作业`，Excel 直接打开。

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 打开是「名单为空」 | 首次启动的导入还没完成（几秒），或名单被删空 → 名单管理里添加/导入 |
| 点格子没反应 | 点在格子之间的空隙了；或者手指滑动被识别成翻页 |
| 表盘时间挡住了标题 | 截图发我，把对应的 top padding 调大即可 |
| 想恢复出厂名单 | 设置 → 恢复内置名单；或卸载重装 |
| 数据会丢吗 | 卸载 App 会清空；升级安装（adb install -r）不会 |
